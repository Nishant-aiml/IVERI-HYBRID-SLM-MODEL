## P9-BUG-001 — Eval dataset registry crash (FIXED)

**Severity:** High  
**File:** `data/pipeline/registry.py`  
**Symptom:** `float() argument must be a string or a real number, not 'NoneType'` for `arc.yaml`, `gsm8k.yaml`, `hellaswag.yaml`, `piqa.yaml`, `winogrande.yaml`  
**Root cause:** Eval-only specs set `quality_threshold: null` and `quality_backend: null`; registry called `float(None)`.  
**Fix:** Handle `None` for eval-only specs; default threshold to 0.0, backend to `"none"`.  
**Verification:** Registry now discovers 11/11 specs.
