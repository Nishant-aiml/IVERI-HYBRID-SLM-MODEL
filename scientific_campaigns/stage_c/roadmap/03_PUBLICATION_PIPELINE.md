## Publication Readiness Index (PRI) Checklist

Each paper tracks completion across 12 mandatory criteria:

- [ ] **RQ Mapping**: Clear research question definition
- [ ] **Hypothesis Testing**: Formulated H0/H1 with decision rules
- [ ] **Baselines**: Parameter & compute-matched baseline comparison
- [ ] **Statistical Integrity**: Welch t-test / ANOVA with Holm correction
- [ ] **Vector Figures**: High-resolution SVG/PDF plots
- [ ] **LaTeX Tables**: Auto-generated LaTeX tables
- [ ] **Complete Ablations**: Tier 1 & 2 component ablations
- [ ] **Failure Analysis**: Explicit failure mode detection report
- [ ] **Limitations Section**: Transparent negative results discussion
- [ ] **Compute Accounting**: FLOPs, wall-clock, and energy breakdown
- [ ] **Reproducibility Badge**: Docker environment & 1-command script
- [ ] **Reviewer Attack Simulation**: Defense against 5 synthetic reviewer attacks

**Target Score:** PRI ≥ 95% before submission.
