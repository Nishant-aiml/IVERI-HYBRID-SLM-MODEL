## Patent Readiness Index (PatRI) Checklist

- [ ] **Novelty Evidence**: Differentiated from prior art (MoE, LLaMA, Mamba)
- [ ] **Prior-Art Comparison Matrix**: Explicit claim boundary mapping
- [ ] **Empirical Technical Effect**: Statistically significant performance gain
- [ ] **Enablement Proof**: Complete reproducible specification
- [ ] **System Claims**: Hardware/software architecture claim scope
- [ ] **Method Claims**: Process flow step claim scope
- [ ] **Fallback Claims**: Dependent claims for patent office prosecution
- [ ] **Alternative Embodiments**: Non-infringing variant coverage
- [ ] **Examiner Package**: Benchmark dataset + execution audit trace

**Target Score:** PatRI ≥ 90% before filing.
